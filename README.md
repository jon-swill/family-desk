# family-desk

Personal, household-only, rules-first investing system. Replaces a 1% advisor with: a low-cost core, a small capped active sleeve, hard risk limits enforced by deterministic code, automatic tax reserves, and a daily view of everything held. LLMs research and propose; plain code decides; the owner approves anything large or risky.

**Start with `TONIGHT.md` (Windows, PowerShell).** New chats start from `docs/HANDOFF.md`.

| Doc | What it is |
|---|---|
| `docs/PRD.md` | Requirements with stable IDs; every phase plan traces to it |
| `docs/RETRO.md` | Owner decisions (closed) and known debt (open) |
| `docs/MASTER_BRIEF.md` | Prompt 0: principles and rules for every session |
| `docs/COMPLIANCE.md` | Laws and provider terms, and how the system enforces them |
| `docs/research/FAILURE_LIBRARY.md` | How others failed, and the rule each failure became |
| `docs/research/STRATEGY_ENCYCLOPEDIA.md` | Every strategy family, its evidence, failure mode and fit |
| `docs/research/NEWS_AND_DATA_STACK.md` | Free/official news and data, and the "why is it moving" pipeline |
| `docs/PROMPTS.md` | Independent review, weekly review and go-live prompts |
| `docs/HANDOFF.md` | Current state, decisions, and the Phase 1 definition |
| `docs/PROJECT_INSTRUCTIONS.md` | Text and file list for the claude.ai project |
| `CLAUDE.md`, `.claude/` | Claude Code instructions, invariants and workflow skills |

Not investment, tax or legal advice. Paper trading only until the Phase 6 gate.
